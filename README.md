# BORZO — серия рекламных роликов (сравнение LUX с копией)

Приватный репозиторий с полным контекстом задачи. Здесь собрано ВСЁ как есть: хронология запроса Руслана (владельца BORZO), три handoff-документа, разбор Instagram, обе прошлые пересборки сценариев и живой голос Руслана из кадра.

## Задача коротко
Руслан (фабрика мебели BORZO, Астана) купил у конкурента стол-трансформер — копию своей модели LUX. Нужна серия из 5 (можно больше) **самостоятельных рекламных роликов** для таргета: сравнение, объяснение цены, краш-тест, «16 гостей», разборка. Съёмка в студии + возможны AI-вставки (интерьеры, бытовые сцены). Главное — **ТЕКСТ**: дословные реплики Руслана, живым человеческим языком, без «ИИ-штампов».

## С чего начать (порядок чтения)
1. `ZADANIE.md` — **само задание** (что сделать, из чего собирать, требования к тексту и формату).
2. `01-hronologia-zaprosa.md` — вся хронология запроса Руслана дословно (голосовые как есть).
3. `context/03-master-context.md` — база бренда, продукт, стиль, стоп-слова.
4. `context/05-current-handoff-АКТУАЛЬНОЕ.md` — самая свежая версия задачи + текущая пятёрка роликов.
5. `context/06-golos-ruslana-instagram.md` — разбор Instagram + транскрипты (живой голос Руслана).
6. Остальные файлы в `context/` — фактура различий, playbook по AI-визуалу, обе прошлые пересборки.
7. `primer-rolik-1-ot-agenta.md` — пример готового Ролика 1 (чтобы видеть планку и формат).

## Структура
