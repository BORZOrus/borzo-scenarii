## ТЕКУЩАЯ ПЕРЕСОБРАННАЯ ПЯТЁРКА (рабочая база)
**Р1 «Похожи? Давайте ближе»** — хук: «Этот стол стоит 170 тысяч. BORZO LUX — 310. Издалека разница действительно не очень понятна. Давайте ближе.» Дальше: стыки → металл/торцы/сварка → механизм → замки → устойчивость. Финал: «Вот теперь можно сравнивать цену. Потому что издалека они действительно похожи.» CTA: полный обзор LUX / менеджер.

**Р2 «Почему BORZO стоит 310 000?»** — хук: «Почему этот стол стоит 310 тысяч? Давайте без слов "премиум" и "высокое качество". Просто покажу.» Дальше: основание+окраска → тройной механизм → 2 фиксатора → минификсы/станок → устойчивость → AI-вставка интерьера/гостей. Финал: «Вот за что мы берём 310 тысяч.» CTA: видеообзор, размеры, цены.

**Р3 «240 кг. Проверим»** — хук: «Производитель заявляет нагрузку 240 килограммов. Ну что. Проверим?» Экшен: стол+мотоцикл, неск.камер, реальный звук. Сломался — назвать факт.результат без злорадства. Выдержал — «Выдержал. Честно — вопросов нет.» (принципиально для доверия).

**Р4 «Куда посадить 16 гостей» (новая версия, AI)** — AI-кадр: гостиная с огромным стационарным столом. «Хотите стол на 16 человек? Тогда есть два варианта.» / «Первый — поставить четырёхметровый стол в гостиной… и следующие 365 дней жить вокруг него.» → реальная консоль: «А можно оставить себе гостиную.» / «На каждый день — элегантная консоль.» → склейка на разложенный LUX/AI-семья: «Нужны гости — выбираете нужную длину. До четырёх метров. До шестнадцати человек.» Финал: «Большой стол нужен иногда. Пространство — каждый день.»

**Р5 «Мы купили его за 170 000»** — хук: «Мы купили этот стол за 170 тысяч. Не для перепродажи. Сейчас покажу зачем.» Распаковка → поверхность → стыки → переворот → уголки/механизм/замки/сварка → детали BORZO. Ключевая мысль: «Именно поэтому стол-трансформер нельзя выбирать только по фотографии.» Финал: «Перед покупкой не спрашивайте только цену. Попросите показать стол целиком.» CTA: подробный видеообзор BORZO.

## ПРАВИЛА СРАВНИТЕЛЬНОЙ ПОДАЧИ (жёстко, юр.аккуратность)
- Не «разносить» словами; камера делает работу.
- Не «подделка/украли/обманывают» без доказательств/юр.проверки.
- Можно: аккуратно о визуальном сходстве + факт покупки конкретного образца.
- Не называть чужую фурнитуру «дешёвой» если класс не установлен — показать тип/размер.
- Не «тройной механизм автоматически лучше» — показать устройство и результат.
- Вид сварного шва НЕ доказывает прочность.
- Не усиливать треск/шатание искусственно. Не вмешиваться в изделие до теста так, чтобы менять результат.
- Один экземпляр ≠ вся продукция бренда. Результат теста не предрешать. Тест ≠ сертификация.
- Не искать специально худший ракурс конкурента, одинаковый свет/ракурс/участок. Если различие не воспроизводится — не использовать.
- Прямое сравнительное размещение в КЗ — юридически проверить до публикации. [ПРОВЕРИТЬ]

## ПРОВЕРИТЬ ДО СЪЁМКИ
Актуальные цены и одинаковые комплектации; полная распаковка + подставка под вставки; регулировка опор/влияние пола на шатание; точная схема двойного/тройного механизма; кол-во и функция замков; технология покрытия чужого стола (не на глаз); техкарта BORZO по окраске/материалам; источник заявления 240 кг и условия; реальная масса/условия архивного теста BORZO.

## СЪЁМОЧНАЯ ЛОГИКА (порядок)
Сначала всё, что требует целого изделия: общие красивые планы обоих → сравнения поверхности/стыков/металла/цвета → механизмы/замки/устойчивость → реплики Руслана → производство BORZO + архив упаковки → нагрузочный тест. ТОЛЬКО ПОСЛЕ теста — полная разборка купленного (если экземпляр один). Нельзя разобрать/пересобрать чужой стол и потом выдавать тест за тест заводской сборки.

## ФОРМАТ ТАРГЕТ-КРЕАТИВА
Вертикаль 9:16. Хук в первые секунды. Один ролик — одна причина досмотреть. Реальный звук деталей важен (щелчок замка, металл, механизм, двигатель). Субтитры минималистичные, один главный факт на экране. НЕ фиксировать искусственно хронометраж — сначала история, потом монтаж, победителей сокращать под performance.
