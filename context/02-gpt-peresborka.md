# Пересборка от GPT (чат Руслана) — что взять

Ключевая правка к варианту Астры:
- Астра сделала ОБРАЗОВАТЕЛЬНУЮ серию (увидеть→понять→проверить→заглянуть→представить), выпуски идут друг за другом.
- Руслану нужны 5 САМОСТОЯТЕЛЬНЫХ рекламных креативов: любой человек впервые видит любой из пяти, за первые секунды цепляется, получает законченную историю, в конце понимает зачем ему BORZO.
- Строить сами 5 основных роликов СРАЗУ пригодными для таргета (не «основной + отдельная 20-сек версия для рекламы»).
- Доступны реалистичные AI-вставки → не ограничены студией (дорогая гостиная с LUX-консолью → склейка на большой стол с гостями).

## Р1 «Похожи? Давайте посмотрим ближе»
Хук: «Этот стол стоит 170 тысяч. BORZO LUX — 310. Издалека разница действительно не очень понятна. Давайте ближе.» → камера резко ближе, макро щели.
Порядок: стыки → металл/торцы/сварка → механизм (двойной/тройной) → замки (1 по центру / 2 на каждую) → устойчивость (оба на один пол, пауза, зритель сам видит).
Финал: «Вот теперь можно сравнивать цену. Потому что издалека они действительно похожи.»
CTA: «Хотите полный обзор LUX — напишите нам.»
Почему таргет: цена + конфликт на первой секунде, законченный ответ даже без других видео.

## Р2 «Почему BORZO стоит 310 000?»
Не оправдание цены — экспертная продажа.
Хук (сильнее астриного «покажу три вещи»): «Почему этот стол стоит 310 тысяч? Давайте без слов "премиум" и "высокое качество". Просто покажу.»
Порядок: основание (сварка, подготовка, грунт, многоэтапная окраска итал. материалами) → перелив золота (оттенок/глубина) → тройной механизм → 2 усиленных фиксатора на столешницу → минификс/посадочные места на оборудовании → устойчивость («стол должен стоять вот так») → AI-вставка (дорогая гостиная с консолью → большой стол с гостями) «А выглядеть — вот так».
Финал: «Вот за что мы берём 310 тысяч.»
CTA: «Видеообзор, размеры и цены — по ссылке.»

## Р3 «240 кг. Ну что, проверим?»
Астра слишком превратила в лабораторный протокол — зрителю не надо минуту на весы. Осторожность по неизвестному результату сохранить.
Хук: стол + эндуро-мотоцикл. «Производитель заявляет нагрузку 240 килограммов.» (пауза, смотришь на мотоцикл) «Ну что. Проверим?» → запуск двигателя.
Экшен: колесо/металл/руки/газ/общий/камера под столом/заезд. На экране только фактическая нагрузка. 8–10 сек без речи.
Если сломался: тишина → крупный план повреждения → «До заявленных 240 получилось вот так» (+ реальная достигнутая нагрузка если известна).
Перебивка: старый тест BORZO «А это наш LUX. Этот тест мы уже проходили.»
Финал: «Поэтому характерис…» [ОБРЕЗАНО — ждём продолжение]
