# BORZO — серия 5 роликов (сравнение с копией LUX)

Собрано из голосовых Руслана + переписки с Астрой + ТЗ. Дата старта: 2026-09-27.

## СУТЬ ЗАДАЧИ
Руслан купил у конкурента стол-трансформер, скопированный с BORZO LUX (в салоне конкурента его даже называют «стол BORZO»). Цена копии ~170 000 ₸, BORZO LUX базовый ~310 000 ₸. Нужна серия из 5 роликов: сравнение, объяснение цены, краш-тест, разборка, брендовая кульминация.

Руслан НЕ импровизатор — нужен готовый пошаговый сценарий, дословный текст под каждую реплику, чтобы прийти и снять. Заморачивается над текстом (что и как говорит). Нужен живой профессиональный язык БЕЗ «ИИ-слов» (палятся). Люди отмечают его компетентность и доверие к лицу — это усиливать конкретикой.

## ПОЗИЦИЯ БРЕНДА (жёстко)
- НЕ называть производителя, НЕ унижать, НЕ «подделка/мошенники/говно/дешман».
- Не истерика, не насмешки, не базар. Спокойный производитель, уверенный в продукте.
- Принцип: «Вот их решение. Вот наше. Смотрите сами.»
- Если узел у копии окажется нормальным — честно сказать. Если тест выдержит — честно показать. Объективность важнее заранее заданного вывода.
- Не «качество», а КОНКРЕТНАЯ вещь: минификсы, тройной механизм, 2 замка на вставку, система покрытия, результат теста с нагрузкой.
- Иногда молчать на очевидном косяке: камера на щель → 2 сек тишины → переход на BORZO. Бывает убийственнее насмешки.
- Лейтмотив серии (рабочий): «Смотрите ближе». Финал Р1: «На фотографии они действительно похожи. Вживую — уже нет.»

## ФАКТУРА РАЗЛИЧИЙ (со слов Руслана, предварительно — стол ещё запакован, часть проверить при вскрытии)
- Покрытие/столешница: у них шагрень местами, царапины, сколы, эстетич. дефекты / у BORZO гладкое иридесцентное.
- Корпус: выраженные щели в стыках, детали установлены неровно, слабая подгонка / у BORZO плотно.
- Металл-основание: геометрич. неровности, кривые элементы, на открытых торцах НЕТ заглушек (видны дырки/отверстия), кривые/плохие сварные швы / у BORZO точная сварка, закрытые торцы.
- Покраска: порошковая полимерка, цвет «дешёвое блестящее золото» / у BORZO итальянские краски+грунты, многоэтапно, как автодеталь, иридесцентный оттенок. [ФОРМУЛИРОВКУ технологии уточнить]
- Устойчивость: шатается на ровном полу / BORZO устойчивый, крепкий.
- Механизм: у них ДВОЙНОЙ / у BORZO ТРОЙНОЙ. ВАЖНО: сам механизм Руслан не разбирал, возможно тот же по качеству — НЕ утверждать, что хуже. Говорить только «двойной vs тройной».
- Замки фиксации столешниц: у них 1 маленький хлипкий по центру / у BORZO по 2 крепких на каждую столешницу.
- Крепёж: дешёвые кривые уголки / у BORZO минификсы, заводская обработка на станках.
- Мелочи: сколы, царапины, нет подставки под столешницы (проверить при вскрытии), упаковка (есть отдельное видео BORZO по упаковке — можно сослаться).

## 5 РОЛЕЙ (не повторять друг друга — 5 разных причин посмотреть)
1. **«Издалека — почти одинаковые»** — главный сравнительный. Хук: два стола, 170 vs 310, издалека похожи → подходим ближе. Разнос глазами по узлам. Финал: «Смотрите ближе». 40–60 сек.
2. **«170 или 310 — за что разница?»** — работа с ценой/возражением. Хук: «Где здесь ещё 140 тысяч? Нормальный вопрос. Показываю.» Монтаж-счётчик по решениям. Финал: «Вопрос не в том, можно ли дешевле. Можно. Вопрос — что для этого придётся изменить.» НЕ утверждать себестоимость конкурента.
3. **Краш-тест «240 кг? Проверим»** — entertainment, зрелищно но честно. Мотоцикл ~200 кг. Хук: «Производитель заявляет 240 кг. Проверим.» НЕ говорить заранее что сломается. Две концовки: А выдержал / Б не выдержал. Перебивка на старый тест BORZO (выдержал). Финал: «Характеристики лучше не писать. Их лучше проверять.» Самый вирусный.
4. **Полная разборка** — «посмотрим туда, куда покупатель не заглядывает». Разобрать по узлам, сравнить с BORZO. Реальные инструменты (уровень/угольник/штангенциркуль/весы) ТОЛЬКО если измерение реально что-то доказывает, не декор. Каждый узел = «что это даёт в реальной эксплуатации».
5. **Брендовая кульминация «Наш стол скопировали»** — спокойная позиция, не обиженная. «Скопировать форму несложно. Сложнее повторить то, чего на фото не видно.» Показ производства BORZO. Финал: «Сравнивайте. Смотрите. Проверяйте. Мы за это только за.» (искать сильнее).

## ТЕХ-ТРЕБОВАНИЯ (из ТЗ)
- Первые 3–6 сек = главный смысл, продукт сразу, смена планов, один ролик = одна мысль.
- 2–3 варианта первых 5 секунд на каждый ролик — тестить на рекламе.
- Звук: музыка не обязательна. Реальные звуки (защёлка, удар по металлу, качание, упаковка, мотор) могут работать сильнее. Указать для каждого: нужна ли музыка, где тишина, какие звуки усилить.
- Субтитры: современные, минималистичные, читаемые, без аляпоти. Факты на экране: 170 000 / 310 000, ДВОЙНОЙ/ТРОЙНОЙ МЕХАНИЗМ, 1 ЗАМОК/2 ЗАМКА, ЗАЯВЛЕНО 240 КГ / ФАКТ ТЕСТ ___.
- CTA разный под функцию ролика. НЕ «успейте заказать/переходите сейчас». Связка «продолжение в след. части» если реально усиливает.
- Фактчек: классифицировать каждое утверждение — ПОДТВЕРЖДЕНО / ПРОВЕРИТЬ ПЕРЕД СЪЁМКОЙ / НЕ ИСПОЛЬЗОВАТЬ ПОКА. Правила сравнительной рекламы РК — короткий список можно/осторожно/нельзя.
- Съёмочный день: сначала целое изделие и красивые кадры, потом разборка, В САМОМ КОНЦЕ разрушительный тест (нельзя сломать до того как сняли целое).
- Самокритика в конце + внести правки.
